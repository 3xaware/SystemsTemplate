# Universal Game Systems (Godot)

## English

This repository contains a collection of **universal core systems** designed to be reused across any game project developed in Godot, regardless of genre or specific mechanics.

The main goal of this project is to **reduce early development time**, prevent **architectural issues at the start of a project**, and provide a **solid, modular, and scalable foundation** on top of which more complex systems can be built.

The included systems cover common needs that **almost every game requires**, such as decoupled communication, scene management, data persistence, and global game flow control.

### Included systems

The full list of systems, along with brief descriptions and links to their individual documentation, can be found here:

➡️ **[Systems README](Systems/README.md)**

### Project scope

This repository **only includes universal systems**, meaning systems that:
- Are not tied to any specific game genre.
- Do not enforce particular gameplay mechanics.
- Do not assume the existence of specific entities such as players, NPCs, or enemies.
- Can be integrated into both small and large projects without major refactoring.

### What is NOT included

This project **does not include** systems or tools that are only relevant to certain types of games, such as:
- Dialogue systems
- NPC systems
- Enemy systems
- Quest systems
- Genre-specific combat mechanics

While these systems are common, they are **not universal**. The intent is for this repository to serve as a foundation for **any type of game**, without imposing unnecessary design constraints.

## Español

Este repositorio contiene un conjunto de **sistemas base universales** diseñados para ser reutilizados en cualquier proyecto de juego desarrollado en Godot, independientemente del género o las mecánicas específicas.

El objetivo principal de este proyecto es **reducir el tiempo de desarrollo inicial**, evitar **problemas de arquitectura tempranos**, y proporcionar una **base sólida, modular y escalable** sobre la cual construir proyectos más complejos.

Los sistemas incluidos cubren necesidades comunes que **prácticamente cualquier juego requiere**, como comunicación desacoplada, manejo de escenas, guardado de datos y control del flujo global del juego.

### Sistemas incluidos

La lista completa de sistemas, junto con una breve descripción y enlaces a su documentación individual, se encuentra en:

➡️ **[Systems README](Systems/README.md)**

### Alcance del proyecto

Este repositorio **solo incluye sistemas universales**, es decir, aquellos que:
- No dependen del género del juego.
- No imponen mecánicas de gameplay específicas.
- No asumen la existencia de entidades concretas como jugador, NPCs o enemigos.
- Pueden integrarse en proyectos pequeños o grandes sin modificaciones profundas.

### Qué NO incluye

Este proyecto **no incluye** sistemas o herramientas que solo aplican a ciertos tipos de juegos, tales como:
- Sistemas de diálogo
- Sistemas de NPC
- Sistemas de enemigos
- Sistemas de misiones
- Mecánicas de combate específicas

Estos sistemas, aunque comunes, **no son universales**. La intención es que este repositorio sirva como base para **cualquier tipo de juego**, sin imponer decisiones de diseño innecesarias.
